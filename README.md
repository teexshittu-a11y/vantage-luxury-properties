# Vantage Private Property
Premium responsive luxury real-estate concept website built with HTML, CSS and JavaScript.

## Features
- Cinematic responsive hero
- Property collection with client-side filters
- Editorial property storytelling
- Advisory and journal sections
- Private enquiry form interaction
- Mobile navigation and scroll-reveal motion
- GitHub Pages ready

## Run
Open `index.html` locally or publish the repository with GitHub Pages (`main` / root).

Photography is loaded from Unsplash for demonstration. Replace with licensed/client assets for production use.
